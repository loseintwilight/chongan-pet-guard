# 验证码显示问题修复说明

## 问题原因

小程序端验证码无法显示的主要原因：

1. **后端地址配置错误** - `config.js` 中配置的是 `localhost:8080`，小程序无法访问本地地址
2. **网络请求超时** - 验证码接口可能响应慢或无法访问

## 修复步骤

### 1. 修改后端地址配置

打开 `pet_system_app/config.js` 文件，修改 `baseUrl`：

```javascript
// 应用全局配置
module.exports = {
	// 开发环境 - 使用你的电脑局域网IP地址
	// baseUrl: 'http://192.168.1.100:8080',  // 替换为你的实际IP
	
	// 生产环境 - 使用你的服务器域名或公网IP
	baseUrl: 'http://your-domain.com:8080',  // 替换为你的实际域名
	
	// ... 其他配置
}
```

### 2. 获取你的局域网IP地址

**Windows系统：**
1. 打开命令提示符（cmd）
2. 输入 `ipconfig`
3. 找到 "无线局域网适配器 WLAN" 或 "以太网适配器"
4. 查看 "IPv4 地址"，例如：`192.168.1.100`

**Mac/Linux系统：**
1. 打开终端
2. 输入 `ifconfig`
3. 找到 `en0` 或 `wlan0`
4. 查看 `inet` 地址

### 3. 确保后端服务正常运行

1. 启动后端服务（pet_system_pc）
2. 在浏览器中测试验证码接口：
   ```
   http://你的IP:8080/captchaImage
   ```
3. 应该返回类似这样的JSON：
   ```json
   {
     "code": 200,
     "msg": "操作成功",
     "img": "base64编码的图片数据...",
     "uuid": "验证码的唯一标识",
     "captchaEnabled": true
   }
   ```

### 4. 小程序配置域名白名单

如果使用真机调试，需要在微信小程序后台配置服务器域名：

1. 登录微信小程序后台
2. 进入 "开发" -> "开发管理" -> "开发设置"
3. 在 "服务器域名" 中添加你的后端地址
4. 注意：必须是 HTTPS 协议（生产环境）

### 5. 开发调试设置

在微信开发者工具中：
1. 点击右上角 "详情"
2. 勾选 "不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"
3. 这样可以在开发时使用 HTTP 协议

## 验证修复

1. 重新编译小程序
2. 打开登录页面
3. 查看控制台日志：
   - 应该看到 "开始获取验证码..."
   - 应该看到 "验证码接口返回数据: ..."
   - 应该看到 "验证码设置成功"
4. 验证码图片应该正常显示

## 常见问题

### Q1: 验证码还是不显示
**A:** 检查以下几点：
- 后端服务是否正常运行
- IP地址是否正确
- 手机和电脑是否在同一局域网
- 防火墙是否阻止了8080端口

### Q2: 提示"后端接口连接异常"
**A:** 
- 检查 `config.js` 中的 `baseUrl` 配置
- 确保后端服务已启动
- 尝试在浏览器中访问后端接口

### Q3: 真机调试验证码不显示
**A:**
- 确保手机和电脑在同一WiFi网络
- 使用局域网IP而不是localhost
- 检查手机是否能ping通电脑IP

## 生产环境部署

生产环境需要：
1. 将后端部署到有公网IP的服务器
2. 配置HTTPS证书
3. 在小程序后台配置服务器域名
4. 修改 `config.js` 中的 `baseUrl` 为生产环境地址
