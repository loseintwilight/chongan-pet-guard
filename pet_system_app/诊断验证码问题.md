# 验证码问题诊断指南

## 🔍 问题诊断步骤

### 第一步：检查后端服务

1. **确保后端服务已启动**
   ```bash
   cd pet_system_pc
   # 启动后端服务（根据你的启动方式）
   ```

2. **在浏览器中测试验证码接口**
   ```
   http://localhost:8080/captchaImage
   ```
   
   应该返回类似这样的JSON：
   ```json
   {
     "code": 200,
     "msg": "操作成功",
     "data": {
       "captchaEnabled": true,
       "uuid": "abc123def456",
       "img": "base64编码的图片数据..."
     }
   }
   ```

### 第二步：检查小程序配置

1. **打开 `pet_system_app/config.js`**
   
   检查 `baseUrl` 是否正确：
   ```javascript
   // ❌ 错误 - 小程序无法访问localhost
   baseUrl: 'http://localhost:8080'
   
   // ✅ 正确 - 使用你的电脑IP
   baseUrl: 'http://192.168.1.100:8080'
   ```

2. **获取你的电脑IP地址**
   
   **Windows:**
   ```cmd
   ipconfig
   # 查找 IPv4 地址，例如: 192.168.1.100
   ```
   
   **Mac/Linux:**
   ```bash
   ifconfig
   # 查找 inet 地址
   ```

### 第三步：检查开发工具设置

1. **打开微信开发者工具**
2. **点击右上角"详情"**
3. **勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"**

### 第四步：查看控制台日志

1. **打开微信开发者工具的控制台**
2. **打开登录页面**
3. **查看是否有以下日志**：

   ```
   开始获取验证码...
   获取验证码，请求URL: http://192.168.1.100:8080/captchaImage
   验证码请求成功，状态码: 200
   验证码响应数据: {...}
   处理后的验证码数据: {...}
   验证码已启用
   验证码UUID: xxx-xxx-xxx
   验证码图片数据长度: xxxx
   ✓ 验证码设置成功
   ```

## 🐛 常见问题排查

### 问题1：提示"后端接口连接异常"

**原因分析**：
- 后端服务未启动
- IP地址配置错误
- 手机和电脑不在同一WiFi
- 防火墙阻止

**解决方案**：
1. 确保后端服务已启动
2. 检查 `config.js` 中的 `baseUrl` 是否正确
3. 在手机浏览器中测试能否访问后端接口
4. 关闭防火墙或添加8080端口例外

### 问题2：验证码图片不显示

**原因分析**：
- 接口返回的数据格式不对
- base64编码的图片数据为空
- UUID为空

**解决方案**：
1. 在浏览器中测试接口，检查返回的JSON格式
2. 查看控制台日志，检查 `img` 和 `uuid` 是否有值
3. 检查后端是否正确生成了验证码

### 问题3：验证码一直在加载

**原因分析**：
- 网络请求超时
- 后端服务响应慢
- 请求被阻止

**解决方案**：
1. 检查网络连接
2. 查看后端服务日志
3. 增加请求超时时间

- [ ] 手机和电脑在同一WiFi
- [ ] 防火墙未阻止8080端口

## 🔧 快速修复

如果上述步骤都检查过了，验证码还是不显示，请按以下步骤操作：

1. **修改 `pet_system_app/config.js`**
   ```javascript
   // 改为你的实际IP
   baseUrl: 'http://192.168.1.100:8080'
   ```

2. **重新编译小程序**
   - 保存所有文件
   - 在微信开发者工具中重新编译

3. **清除缓存**
   - 在微信开发者工具中点击"清除缓存"
   - 重新打开登录页面

4. **查看日志**
   - 打开控制台
   - 查看是否有错误信息
