# 商品购买功能数据库

## 一、新增数据库表

### 1. 支付记录表 tb_payment

| 字段名         | 数据类型     | 说明                                  |
| :------------- | :----------- | :------------------------------------ |
| payment_id     | bigint       | 主键                                  |
| order_id       | bigint       | 关联 tb_order.order_id                |
| payment_method | tinyint      | 支付方式 0 - 微信 1 - 支付宝 2 - 其他 |
| payment_amount | int          | 支付金额（单位：分）                  |
| payment_status | tinyint      | 0 - 待支付 1 - 支付成功 2 - 支付失败  |
| transaction_id | varchar(100) | 支付平台交易号                        |
| payment_time   | datetime     | 支付时间                              |
| create_time    | datetime     | 创建时间                              |
| is_deleted     | tinyint      | 0 - 未删除 1 - 已删除                 |

### 2. 订单状态流转表 tb_order_status

| 字段名       | 数据类型     | 说明                   |
| :----------- | :----------- | :--------------------- |
| status_id    | bigint       | 主键                   |
| order_id     | bigint       | 关联 tb_order.order_id |
| old_status   | tinyint      | 原状态                 |
| new_status   | tinyint      | 新状态                 |
| operate_time | datetime     | 操作时间               |
| operator     | varchar(30)  | 操作人                 |
| remark       | varchar(255) | 备注                   |
| is_deleted   | tinyint      | 0 - 未删除 1 - 已删除  |

### 3. 购物车表 tb_cart

| 字段名      | 数据类型 | 说明                             |
| :---------- | :------- | :------------------------------- |
| cart_id     | bigint   | 主键                             |
| user_id     | bigint   | 关联 sys_user                    |
| shop_id     | bigint   | 关联 tb_shop.shop_id             |
| resource_id | bigint   | 关联 tb_pet_resource.resource_id |
| quantity    | int      | 商品数量，默认 1                 |
| selected    | tinyint  | 0 - 未选中 1 - 选中              |
| create_time | datetime | 创建时间                         |
| update_time | datetime | 更新时间                         |
| is_deleted  | tinyint  | 0 - 未删除 1 - 已删除            |

### 4. 用户收货地址表 tb_user_address

| 字段名         | 数据类型     | 说明                  |
| :------------- | :----------- | :-------------------- |
| address_id     | bigint       | 主键                  |
| user_id        | bigint       | 关联 sys_user         |
| receiver_name  | varchar(50)  | 收货人姓名            |
| receiver_phone | varchar(20)  | 收货人手机号          |
| province       | varchar(50)  | 省份                  |
| city           | varchar(50)  | 城市                  |
| district       | varchar(50)  | 区县                  |
| detail_address | varchar(200) | 详细地址              |
| is_default     | tinyint      | 0 - 否 1 - 是         |
| create_time    | datetime     | 创建时间              |
| is_deleted     | tinyint      | 0 - 未删除 1 - 已删除 |

## 二、订单状态说明

| 状态值 | 状态名称 | 说明                    |
| :----- | :------- | :---------------------- |
| 0      | 待付款   | 订单创建未支付          |
| 1      | 已付款   | 支付完成，待商家处理    |
| 2      | 处理中   | 商家已接单              |
| 3      | 已发货   | 商品已发出              |
| 4      | 已完成   | 用户确认收货            |
| 5      | 已取消   | 超时未付 / 用户主动取消 |

## 三、核心业务流程

| 流程阶段 | 执行步骤                                                     |
| :------- | :----------------------------------------------------------- |
| 用户下单 | 1. 校验商品库存与地址 2. 新增 tb_order，status=0 3. 新增 tb_order_item 4. 扣减 tb_pet_resource.stock |
| 订单支付 | 1. 新增 tb_payment，payment_status=0 2. 调用支付接口 3. 支付成功更新 payment_status=1 4. 更新 tb_order.status=1 5. 写入 tb_order_status 记录 0→1 |
| 订单处理 | 1. 商家更新订单 status=2，记录 1→2 2. 商家发货更新 status=3，记录 2→3 |
| 订单完成 | 1. 用户确认收货更新 status=4，记录 3→4 2. 增加 tb_pet_resource.sales 销量 |
| 订单取消 | 1. 更新 status=5，记录状态变更 2. 回滚商品库存 stock 3. 关闭支付记录 |

## 四、表关系总览

| 主表            | 关联关系 | 从表            | 说明                   |
| :-------------- | :------- | :-------------- | :--------------------- |
| sys_user        | 1:N      | tb_order        | 一个用户多个订单       |
| sys_user        | 1:N      | tb_cart         | 一个用户多个购物车     |
| sys_user        | 1:N      | tb_user_address | 一个用户多个地址       |
| tb_shop         | 1:N      | tb_pet_resource | 一个店铺多个商品       |
| tb_shop         | 1:N      | tb_order        | 一个店铺多个订单       |
| tb_pet_resource | 1:N      | tb_order_item   | 一个商品多个订单项     |
| tb_pet_resource | 1:N      | tb_cart         | 一个商品多个购物车记录 |
| tb_order        | 1:N      | tb_order_item   | 一个订单多个明细       |
| tb_order        | 1:1      | tb_payment      | 一个订单一条支付记录   |
| tb_order        | 1:N      | tb_order_status | 一个订单多条状态记录   |
